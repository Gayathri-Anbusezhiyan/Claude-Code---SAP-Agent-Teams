## Root Cause

SAP Fiori shell bar was not fully rendered when `openSearch()` was called immediately after login. The `[title="Open Search"]` element was not yet present/visible at that point in the login flow. The script was attempting to click the element before SAP completed its post-login session initialization.

## Patch Applied

**File:** `automation/pages/mm/purchase-order/purchase-order.page.js`
**Method:** `openSearch()`

**Change:** Added `waitForSelector('[title="Open Search"]', { state: 'visible', timeout: 30000 })` before the click, ensuring the shell bar is fully loaded before interaction.

```diff
-  async openSearch() {
-    await this.page.locator('[title="Open Search"]').click();
-    await this.page.waitForTimeout(500);
-  }
+  async openSearch() {
+    // Patch 2026-05-19: Wait for shell bar to be fully loaded before clicking search
+    await this.page.waitForSelector('[title="Open Search"]', { state: 'visible', timeout: 30000 });
+    await this.page.locator('[title="Open Search"]').click();
+    await this.page.waitForTimeout(500);
+  }
```

# Self-Healing Patch: TC-CS-021 — openSearch() Timeout

**Patched At:** 2026-05-19T14:36:00Z
**Pipeline Run:** /e2e-automation-v2 CS-2 (re-run 2026-05-19 v3)
**Failure Type:** AUTOMATION_BUG — NAVIGATION_TIMEOUT
**File Patched:** `automation/pages/mm/purchase-order/purchase-order.page.js`
**Method Patched:** `openSearch()`

---

## Root Cause

`openSearch()` waited 30s for `[title="Open Search"]` to be visible. SAP Fiori post-IDP-redirect
and JavaScript framework bootstrap can take longer than 30s in the Playwright runner context,
causing a `TimeoutError` before the shell bar renders. The MCP exploration (Phase 3a) confirmed
SAP itself is fully functional — the selector exists and is clickable once the page loads.

## Change Applied

**Before:**
```javascript
async openSearch() {
  await this.page.waitForSelector('[title="Open Search"]', { state: 'visible', timeout: 30000 });
  await this.page.locator('[title="Open Search"]').click();
  await this.page.waitForTimeout(500);
}
```

**After:**
```javascript
async openSearch() {
  // Self-healing patch (2026-05-19 v3): increased timeout from 30s to 90s.
  // SAP post-login redirect + JS framework bootstrap can exceed 30s in Playwright runner.
  await this.page.waitForLoadState('networkidle', { timeout: 60000 }).catch(() => {});
  await this.page.waitForSelector('[title="Open Search"]', { state: 'visible', timeout: 90000 });
  await this.page.locator('[title="Open Search"]').click();
  await this.page.waitForTimeout(500);
}
```

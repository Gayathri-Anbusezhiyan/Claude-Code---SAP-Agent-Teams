# Self-Healing Patch: TC-CS-021 — openSearch() Locator Fix

**Patch Date:** 2026-05-21
**Pipeline Run:** /e2e-automation-v2 CS-2 (re-run 2026-05-21 v6)
**Patch Type:** LOCATOR_FIX
**File Patched:** `automation/pages/mm/purchase-order/purchase-order.page.js`
**Method Patched:** `openSearch()`

## Problem

TC-CS-021 failed with `TimeoutError` at `openSearch()`:
```
TimeoutError: page.waitForSelector: Timeout 90000ms exceeded.
waiting for locator('[title="Open Search"]') to be visible
```

Root cause: `[title="Open Search"]` selector does not match the Open Search shell bar button.
Phase 3a MCP exploration confirmed the button has accessible name `"Open Search"` via `role=button`,
NOT a `title` attribute. The correct selector is `getByRole('button', { name: 'Open Search' })`.

---

## Change

```javascript
// BEFORE (failing)
async openSearch() {
  await this.page.waitForLoadState('networkidle', { timeout: 60000 }).catch(() => {});
  await this.page.waitForSelector('[title="Open Search"]', { state: 'visible', timeout: 90000 });
  await this.page.locator('[title="Open Search"]').click();
  await this.page.waitForTimeout(500);
}

// AFTER (patched)
async openSearch() {
  // Self-healing patch (2026-05-21 v6): [title="Open Search"] timed out.
  // Phase 3a MCP confirmed button uses role=button name="Open Search", not title attribute.
  await this.page.waitForLoadState('networkidle', { timeout: 60000 }).catch(() => {});
  const searchBtn = this.page.getByRole('button', { name: 'Open Search' });
  await searchBtn.waitFor({ state: 'visible', timeout: 90000 });
  await searchBtn.click();
  await this.page.waitForTimeout(500);
}
```

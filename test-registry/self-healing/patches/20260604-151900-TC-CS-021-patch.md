- **Failing At:**     Fixture initialization → navigateToApp() → shellBar.searchButton
- **Error Message:**  `All locator strategies failed for: shellBar.searchButton`
- **Test Status:**    FAILED (retries: 2, both failed with same error)

---

## Root Cause

The Playwright test fixture `purchaseOrderPage` (defined in `automation/pages/mm/purchase-order/purchase-order.fixtures.js`) calls `navigateToApp()` immediately after login completes (line 46). However, the SAP Fiori shell bar—which contains the "Open Search" button required by `navigateToApp()`—is **lazy-loaded and takes 10-15 seconds to render** after the login redirect.

When the fixture setup runs, the shell bar does not yet exist in the DOM. The `loc('shellBar.searchButton')` method waits for the element with a 15-second timeout, but the timeout starts counting **during fixture setup**, before the shell bar has begun loading. The element never appears within the timeout window, causing all locator strategies to fail.

**Key Finding:** The locator strategies themselves are **NOT at fault**. Both the CSS `[title="Open Search"]` and the role `button { name: 'Open Search' }` locators work perfectly when the shell bar is present. The issue is purely **fixture initialization timing**.

---

## Prior Healing Attempts

Two prior patches were applied to TC-CS-021:

1. **2026-05-29:** Added prerequisite "Open Menu" click to trigger shell bar render (INTERACTION_UPDATE)
2. **2026-06-02:** Increased `loc()` method timeout from 5s → 15s for primary, 3s → 8s for fallbacks (WAIT_UPDATE)

These patches were correct in identifying that the shell bar is slow to load, but they did not solve the root problem: the fixture calls `navigateToApp()` **before the shell bar starts rendering**, so no amount of timeout increase can help.

## Fix Applied

### File: `automation/pages/mm/purchase-order/purchase-order.fixtures.js`

**Line 42-46 (before patch):**
```javascript
    // Step 3: Dismiss guided tour if present
    await poPage.dismissGuidedTour();

    // Step 4: Navigate to Manage Purchase Orders app
    await poPage.navigateToApp();
```

**Line 42-50 (after patch):**
```javascript
    // Step 3: Dismiss guided tour if present
    await poPage.dismissGuidedTour();

    // PATCHED 2026-06-04: Wait for shell bar to be fully loaded before navigating
    // SAP Fiori shell bar (including Open Search button) is lazy-loaded 10-15 seconds after login
    // Without this wait, navigateToApp() fails with "All locator strategies failed for: shellBar.searchButton"
    await page.waitForSelector('[title="Open Search"]', { state: 'visible', timeout: 20000 });

    // Step 4: Navigate to Manage Purchase Orders app
    await poPage.navigateToApp();
```

**Change Summary:**
- **Added:** Explicit `waitForSelector('[title="Open Search"]', { state: 'visible', timeout: 20000 })` after `dismissGuidedTour()` and **before** `navigateToApp()`
- **Timeout:** 20 seconds (conservative — re-execution observed 10-15s average load time)
- **Selector:** Uses the CSS `[title="Open Search"]` locator confirmed working in re-execution
- **Placement:** In fixture setup, ensuring shell bar is ready before any test-specific navigation begins

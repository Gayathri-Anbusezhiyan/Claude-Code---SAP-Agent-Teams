# Patch: TC-CS-001 — 2026-07-31 (v2 - CSS Prioritization)

## Failure Summary
- TC ID        : TC-CS-001
- Story        : CS-2
- Error Type   : Multiple failures - LOCATOR_FAILURE + NAVIGATION_FAILURE
- Root Issues  : Role-based selectors ambiguous; navigation timeouts

## Root Cause
1. **Order button**: Role-based locator matched 2 elements (shell title + footer button)
2. **Search box**: Role-based combobox locator unreliable during navigation
3. **General issue**: SAP's complex UI requires more specific CSS selectors for stability

## Fix Applied

### Comprehensive CSS Locator Strategy

**File: automation/pages/mm/purchase-order/purchase-order.locators.js**
- **Changed**: Entire locator structure from role-based to CSS-prioritized
- **New Structure**: Each locator now has `primary` (CSS) + `fallbacks` (role-based)
- **Key Changes**:
  - `SHELL_BAR.SEARCH_COMBOBOX`: `input[type='search']` (was role combobox)
  - `LIST_PAGE.CREATE_PO_BUTTON`: `button[id*='addEntry']:has-text('Create')` (was role button)
  - `FOOTER.ORDER_BUTTON`: `button:has-text('Order')` (was role button with description)
  - `HEADER.SUPPLIER_INPUT`: `input[id*='Supplier'][id*='input']` (was role textbox)
  - `ITEMS.MATERIAL_INPUT`: `input[id*='Material']:not([id*='MaterialGroup'])` (was role textbox)
  - All form inputs: CSS `input[id*='FieldName']` patterns

**File: automation/pages/mm/purchase-order/purchase-order.page.js**
- **Updated**: `submitPurchaseOrder()` method to use locators file (was hardcoded)
- **Helper Function**: Updated `getPlaywrightLocator()` to support primary/fallbacks structure

**Wait Times Increased** (WAITS object):
- `PAGE_LOAD`: 10s → 15s
- `DRAFT_CREATION`: 10s → 15s
- `PO_SUBMISSION`: 5s → 10s
- `SEARCH_RESULTS`: 2s → 3s

### Rationale
- **CSS selectors** are more specific and stable in SAP's dynamic UI
- **ID patterns** (`[id*='FieldName']`) remain stable across sessions
- **Text selectors** (`button:has-text('Order')`) avoid role ambiguity
- **Fallbacks** provide graceful degradation if SAP UI changes

### Example Locator Structure
```javascript
ORDER_BUTTON: {
  primary: { strategy: 'text', value: "button:has-text('Order')" },
  fallbacks: [
    { strategy: 'role', role: 'button', name: 'Order', description: 'Default Action' }
  ]
}
```

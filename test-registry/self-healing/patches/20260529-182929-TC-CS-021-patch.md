# Patch: TC-CS-021 — 2026-05-29 18:29:29

## Failure Summary
- TC ID        : TC-CS-021
- Story        : CS-2
- Error Type   : TIMEOUT_ERROR (underlying cause: ELEMENT_NOT_PRESENT initially)
- Failing At   : openSearch() — search button locator
- Error Message: "Test timeout of 120000ms exceeded. Error: locator.waitFor: Test timeout of 120000ms exceeded waiting for locator('[title=\"Open Search\"]') to be visible"

## Root Cause

SAP Fiori Launchpad uses lazy rendering for shell bar action buttons. After initial login, the "Open Search" button is **not in the DOM**. The button only becomes available after the first user interaction with the shell bar (specifically, clicking the "Open Menu" hamburger icon). This is a performance optimization to reduce initial page load time.

The script waited for the search button immediately after login, but the element did not exist yet — causing a 120-second timeout.

## Fix Applied

### File: automation/pages/mm/purchase-order/purchase-order.page.js

**Change Type**: INTERACTION_UPDATE (prerequisite action)

**Method Modified**: `openSearch()`

**Changes**:
1. **Added**: Conditional check for "Open Search" button visibility using `isVisible()`
2. **Added**: If button not visible, click "Open Menu" (`getByTitle('Open Menu')`) to trigger full shell bar render
3. **Added**: Wait 1000ms for shell bar re-render to complete
4. **Added**: Close navigation menu by clicking "Open Menu" again (optional — button stays visible)
5. **Changed**: Locator from `locator('[title="Open Search"]')` (CSS) to `getByRole('button', { name: 'Open Search' })` (semantic role)
6. **Reduced**: Final wait timeout from 90000ms to 15000ms (button becomes available quickly after prerequisite step)

**Old Code**:
```javascript
async openSearch() {
  await this.page.waitForLoadState('domcontentloaded', { timeout: 60000 }).catch(() => {});
  const searchBtn = this.page.locator('[title="Open Search"]');
  await searchBtn.waitFor({ state: 'visible', timeout: 90000 });
  await searchBtn.click();
  await this.page.waitForTimeout(500);
}
```

**New Code**:
```javascript
async openSearch() {
  await this.page.waitForLoadState('domcontentloaded', { timeout: 60000 }).catch(() => {});

  // Step 1: Check if "Open Search" button is already visible
  const searchBtn = this.page.getByRole('button', { name: 'Open Search' });
  const isSearchVisible = await searchBtn.isVisible().catch(() => false);

  if (!isSearchVisible) {
    // Step 2: Click "Open Menu" to trigger shell bar full render
    const openMenuBtn = this.page.getByTitle('Open Menu');
    await openMenuBtn.waitFor({ state: 'visible', timeout: 30000 });
    await openMenuBtn.click();
    await this.page.waitForTimeout(1000);

    // Step 3: Close the navigation menu
    await openMenuBtn.click();
    await this.page.waitForTimeout(500);
  }

  // Step 4: Now "Open Search" button should be visible
  await searchBtn.waitFor({ state: 'visible', timeout: 15000 });
  await searchBtn.click();
  await this.page.waitForTimeout(500);
}
```

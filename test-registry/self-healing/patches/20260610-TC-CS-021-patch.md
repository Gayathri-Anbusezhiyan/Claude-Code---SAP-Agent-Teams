**Patch Date:** 2026-06-10
**Self-Healing Agent:** self-healing-agent v1.0

---

## Summary

**Original Failure:** Test failed during fixture setup (before reaching the designed failure point) due to timeout waiting for SAP Fiori shell bar to load after login.

**Root Cause:** The shell bar search button `[title="Open Search"]` lazy-loads 10-25 seconds after login redirect. The hardcoded 20-second timeout in `purchase-order.fixtures.js:48` was insufficient in some conditions.

**Resolution:** Increased timeout from 20000ms to 30000ms to accommodate shell bar lazy-loading variability observed in the SAP demo tenant.

**Change Type:** `WAIT_UPDATE`

## Files Modified

### 1. `automation/pages/mm/purchase-order/purchase-order.fixtures.js`

**Location:** Line 45-48
**Change:** Increased `timeout` parameter from `20000` to `30000` in `page.waitForSelector` call

**Before:**
```javascript
// PATCHED 2026-06-04: Wait for shell bar to be fully loaded before navigating
// SAP Fiori shell bar (including Open Search button) is lazy-loaded 10-15 seconds after login
// Without this wait, navigateToApp() fails with "All locator strategies failed for: shellBar.searchButton"
await page.waitForSelector('[title="Open Search"]', { state: 'visible', timeout: 20000 });
```

**After:**
```javascript
// PATCHED 2026-06-04: Wait for shell bar to be fully loaded before navigating
// PATCHED 2026-06-10: Increased timeout from 20000ms to 30000ms
// SAP Fiori shell bar (including Open Search button) is lazy-loaded 10-25 seconds after login
// Observed during self-healing re-execution: shell bar can take 20+ seconds in certain conditions
// Without this wait, navigateToApp() fails with "All locator strategies failed for: shellBar.searchButton"
await page.waitForSelector('[title="Open Search"]', { state: 'visible', timeout: 30000 });
```

**Rationale:**
- Re-execution confirmed the locator `[title="Open Search"]` is correct and finds the element
- The 20-second timeout was insufficient for shell bar lazy-loading in some conditions
- Increased to 30 seconds provides buffer while staying well below the 2-minute Playwright default
- This is the second patch to this line (first was 2026-06-04 to add the wait entirely)

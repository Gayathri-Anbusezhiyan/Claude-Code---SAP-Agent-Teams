## Description

As a Sales Representative, I want to process a Free Goods (Sample) order for a healthcare provider, so that physicians can evaluate the pharmaceutical product before prescribing it to patients, while ensuring compliance with promotional sample regulations.

## Acceptance Criteria

1. The user can create a Sales Order with an order type designated for "Free Goods" or "Promotional Samples".
2. The system automatically sets the pricing condition to zero for all line items in the Free Goods order.
3. The system requires the user to specify a reason code for the free goods (e.g., "New Product Launch", "Physician Sample", "Patient Assistance").
4. The system validates that the customer is an approved healthcare provider eligible to receive promotional samples.
5. The system tracks the cumulative quantity of free goods shipped to each healthcare provider for compliance reporting.
6. The system prevents processing of Free Goods orders if the healthcare provider has exceeded the annual sample limit or if the material is restricted from promotional sampling.

## Description

## Background

After the SME initiates the workflow, the designated reviewer must complete their assigned review task to advance the workflow to the final review stage. This story covers the reviewer's authentication, task access, and task completion with the required verdict and review context.

## What This Story Covers

The Reviewer authenticates to Veeva Vault QualityDocs using their credentials, navigates to the Home view, selects the recently assigned workflow task from the task list, completes the task by providing Verdict ("Review Completed") and Review Context ("Quality Review"), and submits the task — causing the document to transition from In Review to Review Completed and a final review task to be assigned to the SME.

## Roles

* **Primary actor:** Reviewer — completes the assigned review task with verdict and context
* **Supporting roles:** None (SME becomes active again in CS-14)

## Preconditions

* CS-12 is complete: the workflow has been initiated and a task has been assigned to the reviewer
* Reviewer account has valid credentials and Reviewer role permissions
* The workflow task is visible in the reviewer's Home view task list
* Document is in In Review state

## Workflow Context

State before: Document is in In Review; reviewer has an assigned workflow task visible in their Home view  
State after:  Document is in Review Completed; final review task is assigned to the SME

## Acceptance Criteria

### Happy Path

* \[RP-FUNC-001\] The Reviewer can authenticate to Veeva Vault QualityDocs using role-specific credentials
* \[NAV-001\] After entering the application URL and submitting valid credentials, the reviewer gains access to the QualityDocs module
* \[RP-FUNC-005\] The Reviewer can navigate from the QualityDocs landing page to the Home view
* \[NAV-005\] After clicking "Home" in the navigation, the Home view is displayed with a task list
* \[RP-FUNC-011\] The recently assigned workflow task is visible in the reviewer's task list
* \[AR-007\] The task list displays recently assigned tasks with the most recent at the top
* \[NAV-006\] The Reviewer can select the recently assigned workflow task from the list
* \[RP-FUNC-006\] The task form is displayed with Verdict and Review Context fields
* \[RP-DATA-004\] The Verdict field is a dropdown with predefined values including "Review Completed"
* \[RP-DATA-005\] The Review Context field is a dropdown with predefined values including "Quality Review"
* The Reviewer can select "Review Completed" from the Verdict dropdown
* The Reviewer can select "Quality Review" from the Review Context dropdown
* The Reviewer can submit the completed task form
* \[AR-003\] After task submission, the document status transitions from In Review to Review Completed
* \[AR-004\] After task submission, a final review task is created and assigned to the Quality Doc SME
* \[RP-FUNC-010\] The SME sees the final review task in their Home view task list after the reviewer completes their task
* \[RP-DATA-002\] The document status field displays "Review Completed" after the reviewer submits the task

### Alternative Paths

* If multiple tasks exist in the reviewer's task list, the reviewer can identify and select the most recently assigned task by its position at the top of the list

### Validation and Error Cases

* \[GR-004\] The Verdict field is mandatory; the system prevents task submission when Verdict is not selected
* \[GR-004\] The Review Context field is mandatory; the system prevents task submission when Review Context is not selected
* \[RP-DATA-008\] When a mandatory field is empty, the system displays an error message near the field and blocks form submission
* \[AR-006\] When the user attempts to submit the task with missing mandatory fields, the system displays a validation error and does not allow submission
* \[GR-003\] Only the assigned Reviewer can view and complete this task; other users cannot access or submit it
* \[RP-ROLE-002\] The system enforces role-based access control: only the assigned reviewer can complete their assigned review task
* \[RP-NFR-004\] The system validates all mandatory fields before allowing task submission
* \[RISK-006\] The system shall prevent task completion when Verdict or Review Context fields are missing — HIGH severity risk mitigation

### Business Rules

* \[BR-003\] The Reviewer must provide a Verdict when completing their review task
* \[BR-004\] The Reviewer must provide Review Context when completing their review task
* \[RP-BIZ-003\] Both Verdict ("Review Completed") and Review Context ("Quality Review") must be provided to complete the review task
* \[BR-006\] Only assigned users can access their respective workflow tasks

## Description

As a Production Planner, I want the system to run MRP to generate Planned Orders for upcoming batch production based on the demand plan and current inventory, so that raw material procurement and production scheduling are aligned with anticipated customer demand.

---

## Acceptance Criteria

1. The user can access the "Stock/Requirements List" or "Schedule MRP Runs" Fiori app.
2. The system generates planned orders based on net requirements calculated from sales orders, forecasts, and current stock levels.
3. The system accounts for minimum batch size and lot-sizing rules defined for the finished product.
4. The planner can convert planned orders into process orders or purchase requisitions directly from the planning result.
5. The system flags any planned order affected by a raw material shortage or shelf-life constraint.
6. The system displays a capacity overview to help the planner sequence orders against available cleanroom/suite capacity.

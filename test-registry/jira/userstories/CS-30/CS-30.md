## Description

As a Material Master Data Specialist, I want to create a Material Master record for a new API with a defined shelf-life profile and batch management indicator, so that the material is correctly controlled through procurement, inventory, and production processes.

## Acceptance Criteria

1. The user can access the "Manage Material Master" Fiori app.
2. The system requires the batch management indicator to be set for materials flagged as GMP-regulated in the material type configuration.
3. The system requires entry of total shelf life and minimum remaining shelf life on the Plant Data / Storage view.
4. The system requires an assigned Quality Management inspection type for GMP-relevant materials.
5. The material record cannot be released for procurement until all mandatory GMP fields are completed.
6. A change log captures all subsequent modifications to regulatory-relevant fields for audit purposes.

## Description

As a Sales Order Processor, I want the system to validate that the customer's pharmacy or wholesaler license is valid and not expired before releasing a sales order, so that we remain compliant with pharmaceutical distribution regulations.

## Acceptance Criteria

1. The user can create a Sales Order for a pharmaceutical customer.
2. The system checks the customer master record for the presence of a valid pharmacy/wholesaler license number and expiration date.
3. The system blocks release of the Sales Order if the license is missing, expired, or within a configurable warning period (e.g., 30 days before expiration).
4. The system displays a clear error message indicating the license validation failure and provides the license expiration date.
5. The user can override the block with appropriate authorization (e.g., for emergency/compassionate use orders).
6. The system logs all license validation checks and overrides for audit purposes.

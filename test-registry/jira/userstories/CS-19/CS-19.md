## Description

As a Plant Manager, I want to place a specific batch of raw material on Quality Hold, so that no further goods movements can consume that batch while a deviation investigation is in progress.

## Acceptance Criteria

1. The user can access the "Manage Stock" or "Batch Where-Used List" Fiori app.
2. The user can select a specific batch and change its stock status to "Blocked" or "Quality Inspection."
3. Once blocked, the system prevents any goods issue transaction against that batch, including production order consumption.
4. The system logs the reason code and the user who initiated the hold, along with a timestamp.
5. The system allows an authorized QA user to release the hold once the investigation is closed, restoring the batch to Unrestricted-Use stock.
6. A notification is sent to Production Planning when a batch used in an active process order is placed on hold.

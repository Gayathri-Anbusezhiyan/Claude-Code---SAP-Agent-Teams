## Description

As a Production Operator, I want to record Environmental Monitoring readings (e.g., cleanroom particle counts, temperature, humidity) against an active Process Order, so that environmental conditions during manufacturing are documented as part of the batch record.

---

## Acceptance Criteria

1. The user can access the "Confirm Process Order" Fiori app with an environmental monitoring input step.
2. The system requires entry of environmental readings at the process order operations flagged as environmentally controlled.
3. The system compares entered readings against predefined acceptable ranges and flags any out-of-range value.
4. An out-of-range environmental reading automatically triggers a linked deviation record.
5. Environmental monitoring data is included in the compiled Electronic Batch Record.
6. A trend report is available to track environmental conditions across batches and production suites over time.

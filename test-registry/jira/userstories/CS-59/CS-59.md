## Description

As a Production Supervisor, I want to initiate a Rework Order for a batch that failed final inspection but is eligible for reprocessing, so that the batch can be brought back into specification under a controlled and documented process.

---

## Acceptance Criteria

1. The user can access the "Create Process Order" Fiori app with an order type designated for rework.
2. The system only allows a rework order to be created against a batch with a documented QA disposition approving rework.
3. The rework order references the original batch and captures the approved rework procedure/recipe.
4. The system maintains full batch traceability linking the reworked batch to the original failed batch.
5. The reworked batch is subject to the same quality inspection and in-process control requirements as standard production.
6. The batch record for the reworked batch documents the original failure and the approved rework justification.

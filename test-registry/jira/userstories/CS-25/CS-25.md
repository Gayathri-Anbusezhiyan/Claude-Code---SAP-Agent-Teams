## Description

As a Warehouse Operator, I want to perform a Batch-Specific Physical Inventory count for cold-chain-stored biologics, so that inventory accuracy is validated and any discrepancies are documented for regulatory audit purposes.

## Acceptance Criteria

1. The user can access the "Manage Physical Inventory" Fiori app.
2. The system allows the user to generate a count document filtered by storage location and batch.
3. The user can enter counted quantities against each batch within the designated storage bin.
4. The system calculates and displays variances between book quantity and counted quantity by batch.
5. Variances exceeding a configurable tolerance threshold require a documented reason and supervisor approval before posting.
6. The system maintains a complete count history for audit trail purposes.

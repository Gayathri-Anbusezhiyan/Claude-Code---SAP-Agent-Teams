## Description

## Background

After the Reviewer has completed their review task and recorded their verdict, the workflow returns to the Quality Doc SME for final confirmation. The SME must log back in, locate the final review task assigned to them, and close it with the verdict "No Changes Required – Review Complete". This is the final step of the Send for Review and Verification workflow, formally completing the review cycle.

## What This Story Covers

The ability for the Quality Doc SME to log in to Veeva Vault QualityDocs (in a fresh session after the Reviewer has completed their task), navigate to the Home view, locate their assigned final review workflow task, complete it by selecting the verdict "No Changes Required – Review Complete", and click Complete to close the workflow. Also covers the post-workflow logout.

## Roles

* **Primary actor:** Quality Doc SME — completes the final review task to formally close the workflow
* **Supporting roles:** None (Reviewer has already completed their task)

## Preconditions

* CS-9 (STORY-002) has been completed: the Reviewer has completed their review task and submitted it
* The document is in Review Completed state and the Quality Doc SME has been assigned a final review workflow task
* The Quality Doc SME has valid credentials (QualDocSme.01 account) to log in

## Workflow Context

State before: Document is in Review Completed; Quality Doc SME has an assigned final review task  
State after: Workflow is closed; document is in Final Review Complete state

## Notes

* The SME logs in again using the QualDocSme.01 account — this is a fresh session, distinct from the session used in CS-8 (STORY-001).
* The final review task is accessed from the Home view, identical in navigation pattern to the Reviewer's task in CS-9 (STORY-002).
* The Review Context field is described for the reviewer's task only. The SME final review task form may or may not include a Review Context field — only the Verdict field is asserted.
* Covers: RP-FUNC-009, RP-FUNC-010, RP-FUNC-011, RP-ROLE-003, RP-ROLE-006, RP-WFLOW-007, RP-WFLOW-008, RP-WFLOW-009, RP-WFLOW-010, RP-BIZ-005, RP-DATA-006, RP-DATA-009, RP-DATA-012

## Acceptance Criteria

### Happy Path

* The Quality Doc SME can log in to Veeva Vault QualityDocs using valid credentials and is presented with the QualityDocs interface
* After login, the Quality Doc SME can navigate to the Home view
* The Quality Doc SME's most recently assigned final review workflow task is visible in the Home view
* The Quality Doc SME can open the final review task
* The task completion form displays a Verdict field
* The Quality Doc SME can select "No Changes Required – Review Complete" from the Verdict field options
* The Quality Doc SME can click Complete to submit the final review task
* After submission, the task is marked as complete and the workflow is closed
* The document transitions to Final Review Complete state (workflow ended)
* The Quality Doc SME can log out of the application successfully

### Alternative Paths

* If the SME has multiple tasks in their Home view, they can identify the most recent one corresponding to the final review step

### Validation and Error Cases

* The Verdict field is mandatory; the system does not allow the final review task to be submitted without a verdict selection
* Only the Quality Doc SME assigned to this workflow can complete this final review task; the Reviewer cannot perform this action

### Business Rules

* The SME must complete the final review task with Verdict "No Changes Required – Review Complete" as specified (RP-BIZ-005)
* The final review task is only available after the Reviewer has completed their review task — the workflow is strictly sequential (RP-NFR-001)
* The SME session is a fresh login separate from the Reviewer session (RP-BIZ-007)
* Any authenticated user can log out of the application upon completing their workflow actions (RP-ROLE-006)

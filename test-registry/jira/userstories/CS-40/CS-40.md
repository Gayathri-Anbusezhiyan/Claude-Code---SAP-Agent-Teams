## Description

As a Sales Order Processor, I want the system to perform an Available-to-Promise (ATP) check that excludes batches nearing expiration, so that customers receive products with adequate remaining shelf-life and the risk of returns due to short expiration dates is minimized.

## Acceptance Criteria

1. The user can create a Sales Order for a batch-managed pharmaceutical material.
2. The system performs an ATP check against all unrestricted stock batches.
3. The system excludes batches from the ATP calculation if their remaining shelf-life is less than the minimum required shelf-life threshold (configurable by material, e.g., 6 months before expiration).
4. The system confirms availability and proposes a delivery date only if sufficient stock with adequate shelf-life exists.
5. The system displays a warning message if the ATP check fails due to insufficient stock with adequate shelf-life, even if physical stock is available.
6. The system allows the user to override the shelf-life restriction with appropriate authorization (e.g., for discount sales or urgent orders).

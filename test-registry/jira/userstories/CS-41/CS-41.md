## Description

As a Sales Order Processor, I want the system to perform export compliance denied-party screening for all international pharmaceutical orders, so that we do not ship to sanctioned entities or individuals and remain compliant with export control regulations.

## Acceptance Criteria

1. The user can create a Sales Order for an international customer (ship-to country different from company country).
2. The system automatically screens the customer (Sold-To, Ship-To, Bill-To, Payer) against government-maintained denied-party lists (e.g., OFAC, BIS, EU sanctions).
3. The system blocks release of the Sales Order if the customer or any party matches a denied-party list entry.
4. The system displays a clear error message indicating the export compliance violation and provides the matched party name and list source.
5. The system logs all denied-party screening checks and matches for audit and regulatory reporting.
6. The system allows authorized users (e.g., Export Compliance Officer) to review and override false-positive matches with documented justification.

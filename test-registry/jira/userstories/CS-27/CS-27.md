## Description

As a Procurement Officer, I want to maintain a Purchasing Contract (Outline Agreement) with negotiated pricing for a validated API (Active Pharmaceutical Ingredient) supplier, so that release orders can be issued quickly against pre-agreed terms.

## Acceptance Criteria

1. The user can access the "Manage Purchase Contracts" Fiori app.
2. The user can define target quantity/value, validity period, and tiered pricing conditions on the contract.
3. The system tracks cumulative release quantities/values against the contract limit.
4. The system warns the user when a release order would exceed the remaining contract balance.
5. The contract can be linked to a specific approved vendor and material combination consistent with the source list.
6. The system alerts the Procurement team a configurable number of days before contract expiration.

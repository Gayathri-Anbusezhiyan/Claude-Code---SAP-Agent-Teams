## Description

As a Billing Clerk, I want the system to generate a Billing Document only after the shipped batch has received Quality Assurance release, so that we do not invoice customers for pharmaceutical products that may fail final QA inspection.

## Acceptance Criteria

1. The user can perform goods issue for an Outbound Delivery containing a batch-managed pharmaceutical material.
2. The system checks the QA release status of all batches in the delivery before allowing billing.
3. The system blocks automatic billing if any batch in the delivery does not have a QA release status of "Released" or "Approved".
4. The system sends a notification to the Billing team when a batch receives QA release, triggering billing eligibility.
5. The user can manually create a Billing Document only after all batches in the delivery have been QA-released.
6. The system logs the QA release date and approver information in the Billing Document for traceability.

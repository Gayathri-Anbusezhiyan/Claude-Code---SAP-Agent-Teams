## Description

As a Warehouse Supervisor, I want to capture serialization and Track-and-Trace data at the time of outbound delivery, so that we comply with pharmaceutical serialization regulations (e.g., DSCSA, EU FMD) and can track each unit through the supply chain.

## Acceptance Criteria

1. The user can pick and pack an Outbound Delivery for a serialized pharmaceutical material.
2. The system requires the user to scan or enter the unique serial number for each unit of the serialized material.
3. The system validates that the serial number is valid, has not already been shipped, and matches the batch number in the delivery.
4. The system captures the serial number, batch number, expiration date, and GTIN (Global Trade Item Number) for each unit.
5. The system generates a serialization event record (EPCIS format or equivalent) and uploads it to the Track-and-Trace repository or regulatory reporting system.
6. The system blocks goods issue if serialization data is incomplete or invalid for any unit in the delivery.

## Description

As a Warehouse Operator, I want to transfer consignment stock of a high-value biologic from vendor-owned to company-owned inventory upon usage, so that vendor liability and inventory valuation are correctly reflected.

## Acceptance Criteria

1. The user can access the "Post Goods Movement" Fiori app for consignment withdrawal.
2. The system tracks consignment stock separately by vendor and batch, excluded from company-owned inventory valuation until withdrawn.
3. Upon withdrawal for production or sale, the system automatically transfers ownership and triggers the liability posting to the vendor.
4. The system generates a consignment settlement document listing all withdrawals for a defined settlement period.
5. The settlement document can be used to generate the vendor's invoice verification automatically.
6. The system maintains batch traceability throughout the consignment-to-owned stock transition.

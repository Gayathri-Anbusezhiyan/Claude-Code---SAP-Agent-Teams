## Description

As a Quality Assurance Manager, I want the system to automatically place a Sales and Distribution block on all stock of a recalled batch, so that no further sales orders or deliveries can be created for that batch until the recall is resolved.

## Acceptance Criteria

1. The user can mark a batch as "Recalled" in the batch master record or via a recall transaction.
2. The system immediately places an S&D block on all unrestricted stock of the recalled batch across all plants and storage locations.
3. The system prevents creation of new Sales Orders for the recalled batch.
4. The system prevents release of existing Sales Orders that contain the recalled batch.
5. The system prevents picking and goods issue for Outbound Deliveries that contain the recalled batch.
6. The system sends a notification to all relevant stakeholders (Sales, Warehouse, Quality) when a batch is recalled and blocked.

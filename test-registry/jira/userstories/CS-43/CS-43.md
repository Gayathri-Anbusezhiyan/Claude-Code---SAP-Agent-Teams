## Description

As a Master Data Specialist, I want to create a Customer Master record with credit limit and regulatory license information, so that all pharmaceutical customers are properly validated and credit-controlled before processing sales orders.

## Acceptance Criteria

1. The user can create a Customer Master record in the system with General Data, Company Code Data, and Sales Area Data.
2. The system requires the user to enter a credit limit for the customer in the Company Code Data section.
3. The system allows the user to capture regulatory license information (e.g., Pharmacy License Number, DEA Number, Wholesaler License) in customer master extensions or custom fields.
4. The system validates that the license number is not blank and has a valid expiration date (future date) before saving the customer master.
5. The system assigns a unique customer number upon successful creation of the customer master.
6. The system sends a notification to the Sales and Credit teams when a new pharmaceutical customer is created.

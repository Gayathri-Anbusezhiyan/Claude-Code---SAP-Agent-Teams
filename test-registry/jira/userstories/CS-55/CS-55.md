## Description

As a Quality Assurance Specialist, I want to record a Deviation directly against an in-process control result that falls outside specification, so that any out-of-specification event during production is formally investigated before the batch proceeds.

---

## Acceptance Criteria

1. The user can access the "Create Quality Notification" Fiori app, triggered from the in-process control result entry.
2. The system automatically pre-populates the deviation with the process order, operation, batch, and out-of-spec result.
3. The process order is automatically placed on hold at the affected operation pending deviation disposition.
4. The QA user can document root cause, impact assessment, and corrective/preventive action (CAPA) on the deviation record.
5. The process order cannot proceed to the next operation until the deviation is formally closed with an approved disposition.
6. A trend report is available showing deviation frequency by material, operation, and root-cause category.

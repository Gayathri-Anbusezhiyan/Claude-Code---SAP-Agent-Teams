## Description

As a Master Data Specialist, I want to maintain a Bill of Material (BOM) for a pharmaceutical finished product that includes active ingredient percentages and approved excipient substitutes, so that production always uses a validated and regulatory-compliant formula.

---

## Acceptance Criteria

1. The user can access the "Manage Bills of Material" Fiori app.
2. The system requires each BOM component to reference an approved, active material master record.
3. The system supports alternative/substitute components, each individually flagged with regulatory approval status.
4. Any change to a released BOM triggers a new version and requires re-approval before use in a process order.
5. The system prevents process order creation against a BOM version not in "Released" status.
6. The system maintains a full change history of BOM revisions for regulatory audit purposes.

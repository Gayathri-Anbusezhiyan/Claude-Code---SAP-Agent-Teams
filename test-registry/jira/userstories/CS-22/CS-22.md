## Description

As a Procurement Manager, I want to view an aggregated Vendor Quality Scorecard based on inspection rejection rates and on-time delivery, so that I can make informed sourcing decisions for regulated materials.

## Acceptance Criteria

1. The user can access a "Vendor Evaluation" Fiori analytical app.
2. The system calculates and displays a vendor's batch acceptance rate over a configurable time period.
3. The system displays on-time delivery performance based on PO delivery dates versus actual goods receipt dates.
4. The user can drill down from the scorecard into individual rejected inspection lots.
5. The system flags vendors falling below a configurable quality threshold with a visual indicator.
6. The scorecard can be exported for inclusion in periodic GMP vendor audit reports.

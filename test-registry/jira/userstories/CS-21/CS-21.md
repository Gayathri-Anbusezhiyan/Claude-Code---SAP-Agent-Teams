## Description

As a Warehouse Operator, I want to record a Return Delivery for a rejected batch back to the vendor, so that non-conforming GMP materials are formally removed from inventory with full traceability.

## Acceptance Criteria

1. The user can access the "Post Goods Movement" (Return Delivery) Fiori app.
2. The user can select the original Purchase Order and the specific rejected batch to be returned.
3. The system requires a rejection reason code (e.g., failed specification, damaged packaging, expired) before the return can be posted.
4. The stock is removed from Blocked/Quality Inspection stock upon posting of the return delivery.
5. The system generates a Return Delivery document that references the original goods receipt and inspection lot.
6. A debit memo request can be triggered from the return delivery for vendor cost recovery.

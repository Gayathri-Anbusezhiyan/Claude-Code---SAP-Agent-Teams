## Description

As a Procurement Officer, I want to create a Subcontracting Purchase Order for outsourced fill-finish manufacturing, so that raw materials can be provided to a Contract Manufacturing Organization (CMO) and the finished product received back into inventory.

## Acceptance Criteria

1. The user can access the "Create Purchase Order" Fiori app with item category "Subcontracting."
2. The system allows the user to specify the components to be provided to the CMO against the subcontracted finished material.
3. The system tracks components issued to the vendor as "Stock provided to vendor" inventory.
4. Upon goods receipt of the finished product, the system automatically consumes the corresponding component stock at the CMO.
5. The system triggers a quality inspection lot for the received finished goods per standard GMP receipt rules.
6. The user can view open component balances at the CMO through the "Stock Overview" app.

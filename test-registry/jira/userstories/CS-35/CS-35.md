## Description

As a Warehouse Supervisor, I want to create an Outbound Delivery with Cold-Chain shipping conditions for biologics, so that temperature-sensitive pharmaceutical products are shipped with proper environmental controls and monitoring.

## Acceptance Criteria

1. The user can create an Outbound Delivery from a released Sales Order for a biologics material.
2. The system automatically assigns a "Cold-Chain" shipping condition to the delivery based on the material's temperature requirements (e.g., 2-8°C, -20°C).
3. The system requires the user to specify a temperature-controlled shipping method and carrier that is certified for cold-chain transport.
4. The system blocks picking and packing if the warehouse does not have temperature-controlled storage locations available for the material.
5. The system prints or attaches a "Temperature-Sensitive" label and handling instructions to the delivery documentation.
6. The system records the temperature range and duration requirements in the delivery header for carrier visibility.

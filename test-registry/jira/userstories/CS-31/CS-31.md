## Description

As a Quality Assurance Manager, I want to review and approve a Change Request affecting an approved vendor's manufacturing site, so that materials are not procured from an unapproved or unverified manufacturing location.

## Acceptance Criteria

1. The user can access the "My Inbox" Fiori app to review pending vendor change requests.
2. The system flags any change to a vendor's registered manufacturing site as requiring QA approval before it takes effect.
3. The requestor can attach supporting documentation (e.g., site audit report) to the change request.
4. The system prevents purchase orders from being created against the changed vendor record until QA approval is granted.
5. The system logs the approver, decision, and timestamp for audit trail purposes.
6. Rejected changes return the vendor record to its previous approved state automatically.

## Description

As a Master Data Specialist, I want to create and version a Master Recipe for a pharmaceutical product with defined process parameters and in-process control specifications, so that production is executed consistently according to the validated manufacturing process.

---

## Acceptance Criteria

1. The user can access the "Manage Master Recipes" Fiori app.
2. The system requires the recipe to go through a defined approval workflow before its status changes to "Released."
3. Any change to a released recipe automatically creates a new version, preserving the prior version for audit history.
4. The system prevents a process order from being created against a recipe version that is not in "Released" status.
5. The recipe captures required in-process control checkpoints, target values, and acceptable ranges.
6. The system logs the requestor, approver, and effective date for every recipe version change.

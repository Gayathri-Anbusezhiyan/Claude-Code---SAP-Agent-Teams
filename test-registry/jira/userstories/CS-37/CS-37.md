## Description

As a Customer Service Representative, I want to process a Return Order for a customer complaint about a defective pharmaceutical product, so that the defective batch can be investigated and the customer can receive a credit or replacement.

## Acceptance Criteria

1. The user can create a Return Order referencing the original Sales Order and Delivery.
2. The system allows the user to specify a reason code for the return (e.g., "Defective Product", "Quality Complaint", "Packaging Damage").
3. The system captures the batch number, lot number, and expiration date from the returned product.
4. The system creates a Return Delivery document for goods receipt of the returned product.
5. The system places the returned batch in a "Quality Inspection" stock type for investigation by Quality Assurance.
6. The system creates a quality notification or complaint record linked to the Return Order for investigation and root cause analysis.

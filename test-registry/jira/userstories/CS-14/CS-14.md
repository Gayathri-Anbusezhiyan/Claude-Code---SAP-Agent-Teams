## Description

## Background

After the reviewer completes their task, the workflow returns to the Quality Doc SME for final sign-off. This story covers the SME's second authentication session (explicitly "login back" per the requirement), final review task access, task completion with verdict, and workflow closure via the Complete button. The story also includes the logout action at the end of the workflow.

## What This Story Covers

The Quality Doc SME re-authenticates to Veeva Vault QualityDocs in a fresh session, navigates to the Home view, selects the recently assigned final review workflow task from the task list, completes the task by providing Verdict ("No Changes Required – Review Complete"), clicks the Complete button to close the workflow — causing the document to transition from Review Completed to Final Review Complete and the workflow to close. The SME then logs out from the application.

## Roles

* **Primary actor:** Quality Doc SME — completes the final review task and closes the workflow
* **Supporting roles:** None (reviewer has already completed their task in CS-13)

## Preconditions

* CS-13 is complete: the reviewer has submitted their review task
* Document is in Review Completed state
* Final review task has been assigned to the Quality Doc SME
* SME account has valid credentials and SME role permissions

## Workflow Context

State before: Document is in Review Completed; SME has an assigned final review task visible in their Home view  
State after:  Document is in Final Review Complete state; workflow is closed; user is logged out

## Acceptance Criteria

### Happy Path

* \[RP-FUNC-001\] The Quality Doc SME can re-authenticate to Veeva Vault QualityDocs in a fresh session using role-specific credentials
* \[NAV-007\] After entering the application URL in a fresh session and submitting valid credentials, the SME gains access to the QualityDocs module
* \[RP-FUNC-007\] The Quality Doc SME can navigate from the QualityDocs landing page to the Home view
* \[NAV-005\] After clicking "Home" in the navigation, the Home view is displayed with a task list
* \[RP-FUNC-011\] The recently assigned final review workflow task is visible in the SME's task list
* \[AR-007\] The task list displays recently assigned tasks with the most recent at the top
* \[NAV-008\] The Quality Doc SME can select the recently assigned final review task from the list
* \[RP-FUNC-008\] The final review task form is displayed with a Verdict field and a Complete button
* \[RP-DATA-004\] The Verdict field is a dropdown with predefined values including "No Changes Required – Review Complete"
* The Quality Doc SME can select "No Changes Required – Review Complete" from the Verdict dropdown
* The Quality Doc SME can click the Complete button to submit and close the final review task
* \[AR-005\] After clicking Complete, the document status transitions from Review Completed to Final Review Complete
* The workflow is closed; no further workflow tasks are created or assigned
* \[RP-FUNC-012\] The Quality Doc SME can log out from the application
* \[NAV-009\] After logout, the user session is terminated and the login screen is displayed
* \[RP-NFR-001\] The user session terminates when the user logs out from the application

### Alternative Paths

* If multiple tasks exist in the SME's task list, the SME can identify and select the most recently assigned final review task by its position at the top of the list

### Validation and Error Cases

* \[GR-005\] The Verdict field is mandatory; the system prevents final task submission when Verdict is not selected
* \[RP-DATA-008\] When the Verdict field is empty, the system displays an error message near the field and blocks form submission
* \[AR-006\] When the user attempts to submit the task with a missing Verdict, the system displays a validation error and does not allow submission
* The Complete button must be clicked to finalize and close the workflow; the workflow does not close without this explicit action
* \[GR-003\] Only the Quality Doc SME assigned to this workflow can complete the final review task; the Reviewer cannot perform this action
* \[RP-ROLE-004\] The system enforces role-based access control: only the Quality Doc SME can complete the final review task
* \[RP-NFR-002\] The system enforces role-based access control for all workflow actions
* \[RP-NFR-004\] The system validates all mandatory fields before allowing task submission
* \[RISK-008\] The system shall prevent final task completion when the Verdict is missing — HIGH severity risk mitigation
* \[RISK-007\] The system shall ensure that the final review task is assigned to the SME after the reviewer completes their task — HIGH severity risk mitigation

### Business Rules

* \[BR-005\] The Quality Doc SME must complete the final review task with a verdict
* \[RP-BIZ-004\] The SME must provide Verdict "No Changes Required – Review Complete" and click Complete to close the workflow
* \[BR-008\] User must log out after completing the workflow
* \[BR-006\] Only assigned users can access their respective workflow tasks

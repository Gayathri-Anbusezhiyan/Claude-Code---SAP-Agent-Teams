## Description

As a Production Supervisor, I want to confirm yield and scrap quantities against a Process Order operation, so that actual production output and losses are accurately recorded and reconciled against the planned batch size.

---

## Acceptance Criteria

1. The user can access the "Confirm Process Order" Fiori app.
2. The user can enter yield quantity, scrap quantity, and scrap reason code at each relevant operation.
3. The system calculates and displays the yield variance percentage against the planned batch quantity.
4. A yield variance exceeding a configured tolerance triggers a mandatory deviation record before the order can be technically completed.
5. The system updates the finished goods batch quantity based on confirmed yield.
6. A report is available showing yield trends by material, line, and shift for continuous improvement analysis.

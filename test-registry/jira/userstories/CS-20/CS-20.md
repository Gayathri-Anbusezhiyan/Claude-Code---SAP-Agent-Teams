## Description

As a Procurement Officer, I want to create a Purchase Requisition that automatically routes for approval based on value and material criticality, so that spend on GMP-critical materials receives the appropriate management sign-off before a PO is created.

## Acceptance Criteria

1. The user can access the "Create Purchase Requisition" Fiori app.
2. The system automatically determines the approval workflow (release strategy) based on the requisition's total value and material type.
3. The requisition cannot be converted into a Purchase Order until all required approval steps are completed.
4. Approvers receive a task notification in their Fiori "My Inbox" app with the option to approve, reject, or send back for revision.
5. The system displays the current approval status and history on the requisition.
6. The requisitioner receives a notification when the requisition is fully approved or rejected.

## Description

As a Sales Order Processor, I want the system to automatically determine batches using FEFO (First-Expiry-First-Out) for pharmaceutical sales orders, so that products with the nearest expiration dates are shipped first.

## Acceptance Criteria

1. The user can create a Sales Order for a pharmaceutical material that is batch-managed.
2. The system automatically determines the batch with the nearest expiration date for the order quantity.
3. The system excludes batches that have expired or are within the minimum remaining shelf-life threshold (configurable by material).
4. The system splits the order across multiple batches if a single batch does not have sufficient quantity.
5. The system displays the selected batch number(s) and expiration date(s) in the Sales Order line items.
6. The system sends a warning if no batch with sufficient remaining shelf-life is available for the order quantity.

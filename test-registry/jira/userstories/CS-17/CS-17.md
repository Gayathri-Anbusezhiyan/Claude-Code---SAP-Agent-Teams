## Description

As a Procurement Officer, I want to maintain an Approved Vendor List (Source List) for critical GMP raw materials, so that purchase orders can only be created against vendors who are formally qualified and audited.

## Acceptance Criteria

1. The user can access the "Manage Source Lists" Fiori app.
2. The system allows the user to designate one or more vendors as "Approved" for a specific material and plant combination.
3. The system blocks creation of a Purchase Order for a restricted material if the vendor is not present on the approved source list.
4. The system displays a warning/error message identifying the material as requiring vendor qualification when a non-approved vendor is selected.
5. Approved vendor status can be time-bound with validity start and end dates reflecting audit/certification expiry.
6. The system sends a notification to the Procurement team a configurable number of days before a vendor's approval validity expires.

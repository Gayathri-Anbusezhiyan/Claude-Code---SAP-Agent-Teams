## Description

As a Warehouse Operator, I want to move expired batches to a designated Blocked storage location automatically, so that expired GMP materials cannot be accidentally picked for production or shipment.

## Acceptance Criteria

1. The user can access the "Manage Stock" Fiori app or a scheduled background job for expiration monitoring.
2. The system runs a daily background check comparing batch expiration dates to the current date.
3. Batches identified as expired are automatically restricted from unrestricted-use stock.
4. The system generates a notification to the Warehouse and QA teams listing newly expired batches.
5. An authorized user must complete a disposition (destroy, return, rework) before the batch can be removed from blocked status.
6. The system maintains a report of all expired batch dispositions for regulatory audit.

## Description

As a Production Planner, I want to view a Capacity Planning overview for cleanroom/sterile manufacturing suites, so that process orders are scheduled without exceeding the available validated capacity of shared production resources.

---

## Acceptance Criteria

1. The user can access the "Capacity Planning" or "Monitor Work Center Load" Fiori app.
2. The system displays planned and confirmed load against each work center's available capacity by time period.
3. The system highlights overload situations where scheduled process orders exceed available capacity.
4. The planner can reschedule or resequence process orders directly from the capacity overview.
5. The system accounts for required cleaning/changeover time between batches of different products on the same line.
6. The system reflects updated capacity load immediately after a process order is rescheduled.

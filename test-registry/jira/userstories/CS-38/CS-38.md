## Description

As a Contract Administrator, I want to maintain Rebate Agreements for Group Purchasing Organization (GPO) contracts, so that member hospitals and pharmacies receive the correct volume-based rebates at the end of each contract period.

## Acceptance Criteria

1. The user can create a Rebate Agreement specifying the GPO contract number, validity period, and eligible customers (GPO members).
2. The system allows the user to define rebate tiers based on cumulative purchase volume (e.g., 2% rebate for 0-10,000 units, 4% rebate for 10,001-50,000 units).
3. The system automatically accrues rebate amounts for each eligible customer based on their cumulative purchases during the contract period.
4. The system provides a report showing cumulative purchases and accrued rebates for each GPO member.
5. The user can process a rebate settlement at the end of the contract period, generating credit memos or rebate payments for eligible customers.
6. The system prevents retroactive changes to rebate tiers after the settlement has been processed.

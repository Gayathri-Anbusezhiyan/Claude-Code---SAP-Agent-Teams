## Description

As a Material Planner, I want the system to calculate replenishment requirements for GMP materials using MRP while respecting minimum remaining shelf-life rules, so that newly procured stock always has sufficient shelf life for downstream production use.

## Acceptance Criteria

1. The user can access the "Stock/Requirements List" or run MRP via "Schedule MRP Runs" Fiori app.
2. The system considers the minimum remaining shelf-life requirement defined in the material master when proposing new procurement.
3. Batches that do not meet the minimum remaining shelf-life are excluded from available stock in the MRP availability check.
4. The system generates planned orders or purchase requisitions reflecting adjusted lead times where shelf-life constraints apply.
5. The planner can review and convert planning proposals directly from the Stock/Requirements List.
6. The system issues an exception message when existing stock is approaching the minimum shelf-life threshold.

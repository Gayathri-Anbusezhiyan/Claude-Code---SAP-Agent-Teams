## Description

As a Compliance Officer, I want to generate a Batch Traceability Report showing all goods movements for a specific raw material batch, so that I can respond to a regulatory recall inquiry within the required timeframe.

## Acceptance Criteria

1. The user can access the "Batch Where-Used List" or equivalent traceability Fiori app.
2. The user can search by batch number, material, or vendor batch reference.
3. The system displays all goods receipts, transfers, consumption, and issues associated with the batch, including dates and quantities.
4. The system displays downstream linkage to any process orders or deliveries that consumed the batch.
5. The report can be exported to Excel/PDF for inclusion in a regulatory response package.
6. The system completes the search and generates results within an acceptable performance threshold for time-critical recall situations.

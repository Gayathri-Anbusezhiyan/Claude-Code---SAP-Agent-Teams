### Expected Final Result

- Return Order is successfully created and triggers automatic Credit Memo Request creation
- Credit Memo Request document is generated with a unique document number
- Credit Memo Request is visible in the Return Order document flow and related documents section
- Credit Memo Request contains correct customer, material, quantity, and credit amount data matching the Return Order
- Bidirectional link is established between Return Order and Credit Memo Request
- Credit Memo Request status is "Open" / "In Process" and ready for further processing (approval, billing)
- If applicable, FI/CO accounting document is posted with customer credit entry
- FI/CO integration is successfully established and traceable

---

### Post-conditions

- SAP Return Order document exists with the generated Return Order number
- Return Order status is "Created" / "Open"
- Credit Memo Request document exists with the generated Credit Memo Request number
- Credit Memo Request status is "Open" / "In Process"
- Credit amount is correctly calculated and recorded in the Credit Memo Request
- Bidirectional link is established between Return Order and Credit Memo Request
- FI/CO accounting document may be posted (if auto-posting is configured)

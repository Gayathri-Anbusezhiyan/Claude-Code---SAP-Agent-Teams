| P3 | Master Data | GMP Material `{TD.materialIdConvertPA}` exists, is active, has batch management enabled, and is configured for in-house production |

| P6 | MRP Data | The Planned Order reflects shelf-life constraints and has a valid planned start date and finish date |

### Expected Final Result

- The planner successfully accesses the Planned Order from the Stock/Requirements List
- The Planned Order is reviewed and converted to a Production Order
- The conversion is confirmed by the system with a success message and a Production Order number
- The Planned Order no longer appears in the Stock/Requirements List (status changed to converted)
- The Production Order appears in the Stock/Requirements List as a confirmed production element
- Shelf-life constraints originally applied to the Planned Order are preserved in the Production Order

### Post-conditions

- The Production Order exists in the system with a valid Production Order number
- The Stock/Requirements List reflects the updated status (PA removed, Production Order visible)
- No application-level errors or critical warnings remain outstanding

### Expected Final Result

- SAP displays an authorization error message when the user attempts to manually override the FEFO-proposed batch without the required authorization (V_KONH_VKS)
- The system prevents the batch override from taking effect
- Either the Sales Order creation is blocked entirely with an authorization error, OR the Sales Order is created with the original FEFO-proposed batch (ignoring the unauthorized override attempt)
- The error message clearly communicates the authorization issue to the user
- No Sales Order is created with the unauthorized override batch

---

### Post-conditions

- If authorization error blocks creation: No SAP Sales Order document is created; system state remains unchanged
- If authorization error is bypassed: SAP Sales Order document exists but with FEFO-proposed batch, NOT the attempted override batch
- Authorization violation is logged for audit and security review
- No application-level errors or critical warnings remain outstanding

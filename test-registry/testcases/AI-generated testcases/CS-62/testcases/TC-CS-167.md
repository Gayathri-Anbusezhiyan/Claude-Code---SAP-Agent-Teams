| P4 | Material | Material `{TD.materialId}` for the process order exists and is configured for plant `{TD.plant}` |

| P8 | Stock Status | Finished goods batch `{TD.batchNumber}` exists with stock status "Quality Inspection" (QI) |

### Expected Final Result

- Process order `{TD.processOrderNumber}` is technically completed successfully
- Order status is updated to "TECO" (Technically Completed) in SAP
- All quality gates (deviations closed, IPC results recorded, batch records signed) are verified and passed
- Finished goods batch `{TD.batchNumber}` stock status remains "Quality Inspection" (QI) and does NOT auto-transition to Unrestricted (UR)
- QM inspection lot status for the batch is unaffected by TECO (QA release is a separate action)
- An audit log entry is created capturing: User ID (`{ENV.SAP_USERNAME}`), Timestamp (ISO8601 format), Action code "TECO"
- No application-level errors or blocking warnings remain outstanding

---

### Post-conditions

- Process order status is "TECO" (Technically Completed)
- Stock status for batch remains "QI" (Quality Inspection) — awaiting formal QA release
- Audit log entry for TECO action is persisted in SAP change documents
- Order cannot be modified further except by reversing TECO (if system allows)
- QA release process can now proceed independently to transition stock from QI to UR
